# TRACEN DYP — Talent Intelligence Platform

> **DYP — Discover Your Potential**

DYP is the **Talent Intelligence Engine of TRACEN**, designed to understand an individual's potential, capabilities, career goals, industry readiness, skill gaps, and development trajectory.

Unlike traditional assessment platforms that focus primarily on marks or isolated skill scores, DYP combines **profile information, adaptive assessments, evidence, competency scoring, career intelligence, readiness analysis, and continuous progress** into a single evolving Talent Profile.

The long-term objective is to transform student data and evidence into actionable:

* **Talent Intelligence**
* **Career Compatibility**
* **Industry Readiness**
* **Skill Gap Analysis**
* **Learning Timeline**
* **Personalized Roadmap**
* **AI Recommendations**

---

# 🎯 Vision

DYP is designed to answer four fundamental questions for every student:

> **Where am I?**

> **Where can I go?**

> **What is stopping me?**

> **What should I do next?**

The system does not treat assessment as a one-time event.

## Every assessment, project, course, certification, interview, and milestone can contribute new evidence to the user's profile, allowing DYP to continuously update its understanding of the individual's capabilities and career readiness.

# 📈 Scoring Engine

DYP generates multiple independent capability dimensions rather than relying on a single raw score.

### Core Scores

| Score                               | Meaning                                         |
| ----------------------------------- | ----------------------------------------------- |
| **Cognitive Score (CS)**            | Cognitive capability                            |
| **Technical Foundation Score (TS)** | Technical foundation                            |
| **Execution Score (ES)**            | Ability to execute and solve practical problems |
| **Learning Potential Score (LS)**   | Learning and adaptability potential             |
| **Professional Skills Score (PS)**  | Professional and behavioural capabilities       |

### Overall DYP Score

```text
DYP Score =
25% Cognitive Score
20% Technical Score
20% Execution Score
15% Learning Potential Score
20% Professional Skills Score
```

The scoring model is defined in the current functional specification.

# 🏗️ Architecture

DYP is initially being developed as a **Modular Monolith**.

Each intelligence engine is intended to remain logically independent while operating inside a shared Spring Boot application and PostgreSQL database.

```text
                         TRACEN DYP

                      React Frontend
                             │

                   Spring Boot Backend
                             │
```

# 🔐 Security Principles

Security is being incorporated from the backend foundation stage.

Current principles:

* Never store plaintext passwords.
* Hash passwords using BCrypt.
* Never expose passwords through API responses.
* Keep database credentials outside source control.
* Use DTOs instead of exposing persistence entities directly through APIs.
* Keep business logic inside service layers.
* Validate incoming API data.
* Centralize API exception handling.
* Avoid hardcoded secrets.
* Use environment variables for sensitive configuration.
